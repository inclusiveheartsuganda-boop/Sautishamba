# SautiShamba shareable demo

Open `index.html` in a modern browser. The demo is a self-contained front-end page with no install or build step. Publish the repository root with GitHub Pages to share it as a hosted demo.

The officer desk includes a searchable group list, sample weather/market/transport indicators, a draft recommendation, edit/reject/approve actions, and voice, SMS, large-print and sign-language brief previews. Approval only changes the local demo status; no advice is sent to farmers.

All groups and condition values are illustrative sample data. They are not live forecasts, price feeds or transport quotes. Voice playback uses the browser's built-in speech synthesis when available; it is not a recorded Lumasaba translation. The sign-language brief is an interpreter outline, not a generated video.
